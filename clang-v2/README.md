# CLANG! 哐当 · 拆机联机试炼场 V2

单文件网页 FPS（约 720 KB，无任何外部请求、内置 three.js r150）。印刷废土风沿用 clangclang.top 的纸张 / 网点 / 硬阴影语言，玩法是"波次生存 + 卡牌改装 + 军械换装"。

---

## 1. 文件清单

| 文件 | 说明 |
|---|---|
| `CLANG-v2.html` | 游戏本体，单文件。双击即玩，丢到任何静态托管即可（Cloudflare Pages / GitHub Pages / 对象存储）。 |
| `relay-server.js` | 联机中继，Node + `ws`，房间内广播。不含权威结算。 |
| `build/src/*` | 源码分片：`content.js`（31 枪 + 50 卡 + 程序化枪模）、`game-a.js`（渲染/场景/玩家/输入）、`game-b.js`（战斗/敌人/卡牌/HUD/菜单/联机）、`style.css`、`index.html` |
| `build/build.py` | 一键打包：`python3 build/build.py` → 生成 `CLANG-v2.html` |

改内容只要改 `build/src`，再跑一次 `build.py` 即可，不需要联网。

## 3. 联机怎么接

1. 部署页模式选 **联机 ONLINE (WS)**，填 `wss://你的地址` 和房间号。
2. 起中继：

```bash
npm i ws
node relay-server.js          # 默认 :8080，可用 PORT=8081 改
# 自检：curl http://127.0.0.1:8080/health
```

3. 协议（文本帧 JSON，服务端只做房间内转发 + 发 `peers` 名单）：

```
{t:"join",room,sid,name}
{t:"st",  room,sid,x,y,z,ry,g}       // 12Hz 位置/朝向/当前枪
{t:"shot",room,sid,ox,oy,oz,dx,dy,dz,g}
{t:"kill",room,sid,k}
{t:"wave",room,sid,wave}
{t:"chat",room,sid,msg}
{t:"bye", room,sid}
```

**同机多标签**还能用 `LOCAL`（BroadcastChannel）模式，不需要任何服务端，方便调试。

之后你把后端给我时，最省事的接法是：把 `relay-server.js` 换成权威服务端（服务端算波次/伤害/命中），前端只发输入、只收快照；协议字段不用动，改 `netSend / netHandle` 两处即可。

**31 把枪（真实口径/射速/弹匣/换弹时间，按类别分档）**

- 突击步枪 10：M4A1 卡宾 · HK416 A5 · AK-47 · AK-74M · SCAR-L MK16 · G36C · AUG A3 · FAMAS F1 · AS VAL（消音 9×39）· Mk14 EBR（半自动）
- 冲锋枪 7：MP5A5 · MP7A2 · P90 · UMP45 · Vector .45 · PP-19 野牛（64 发螺旋弹匣）· MPX
- 手枪 4：Glock 17 · M1911A1 · 沙漠之鹰 .50AE · USP45（消音）
- 霰弹 4：雷明顿 870 · 莫斯伯格 590 · SPAS-12 · KSG（14 发双管）
- 狙击 3：AWM .338LM · M24 SWS · M82A1 .50BMG
- 精确/机枪 3：SKS · M249 SAW（100 发弹链）· PKM（7.62×54R 弹链）

枪模是按参数程序化生成的：口径决定机匣/枪管长度，弹匣类型分 STANAG / AK 弯弹匣 / 手枪短匣 / P90 顶置 / 霰弹管仓 / 双管 / 弹链箱 / 栓动弹仓，瞄具有红点/全息/长镜/机械四档，另外消音器、两脚架、木质或沙色涂装都跟着数据走。

**50 张卡**：14 个效果键（伤害 / 射速 / 弹匣 / 换弹 / 扩散 / 生命 / 回血 / 回血延迟 / 移速 / 核心倍率 / 开镜倍率 / 击杀回血 / 得分 / 后坐），稀有度 R1–R4，权重 7 : 4 : 2.4 : 1.1，同类最多叠 3 层。卡牌库能看到全部 50 张和自己的装配数。

**画质**：自建后处理链——亮部提取 → 双向高斯两轮 → ACES 近似 + 青影暖高光分级 + 印刷网点 + 纸纹噪点 + 暗角。设置里有 低/中/高/极致 四档（分辨率倍率 0.72/0.9/1.2/1.55）、渲染分辨率滑杆、泛光强度、FOV、灵敏度、音量。手机默认中画质，桌面默认高画质。

**未验证 / 局限**
- 软件渲染只有 5 fps，**真机 GPU 帧率没有实测**，第一次上手机建议先切中/低画质看帧率
- 敌人 AI 是最简的"追 + 定点射击 + 简易避障"，没有掩体寻路、没有动画骨骼
- 联机是中继转发，不是权威服务端：位置和命中在客户端算，作弊只靠自觉
- 没有账号、没有存档云同步、没有匹配服；`localStorage` 只存最高波次和设置

## 6. 两件事必须说清楚

1. **"比肩 3A" 做不到。** 3A 是几百人 × 几年 × 几千万美元的资产管线。现在这版是把"方向对不对、手感顺不顺、完成度高不高"做扎实的高完成度原型——能玩、能联机、能上手机、能改。
2. **你贴的 `ghp_...` 令牌请立刻去 GitHub → Settings → Developer settings → Personal access tokens 撤销。** 它等于仓库写权限，已经出现在聊天记录里；以后只放服务端环境变量，永远不要进前端。`sb_publishable_...` 是客户端可公开的 publishable key，安全性取决于 Supabase 的 RLS 策略。
